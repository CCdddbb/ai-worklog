# 0.2.0 验证记录

## 自动化

55项Python测试通过，包括旧版37项回归，以及：

- 跨会话范围选择、12会话的有界采样、源文件只读及摘录脱敏。
- 工具输出/思维链不进入快照；预览不触发模型。
- 手动结束冻结范围、阶段总结不关闭任务、去重和显式重试。
- 自动模式不倒灌历史，未完成工具调用不直接触发；同一活动不反复总结。
- 改变模型、授权或来源目录时阻止旧快照。
- 单worker所有权、服务运行时拒绝清理、旧排队任务不能绕过当日执行额度。
- Pi CLI关闭工具/扩展/MCP/上下文文件/持久会话；只取权威结束事件，验证证据引用，限制进程时间及输出。
- HTTP写操作必须有令牌和同源Origin，不接受任意来源路径。

真实Chrome无头测试使用虚构数据库和假模型，验证创建跨会话任务、材料预览、确认结束、异步草稿、日报导出、隐私页和移动布局；页面没有外部资源请求。浏览器与本地服务均在测试结束后清理，不使用Playwright daemon。

## 真实模型验证（合成材料）

使用本机已有Pi模型 `openai-codex / gpt-6.1-sol` 验证：

1. 无工具Pi调用能返回符合JSON结构与证据引用要求的中文结果。
2. 完整流程：写入合成Pi日志 → 只读导入 → 关联任务 → 冻结脱敏快照 → 真实模型总结 → 成功状态与本地持久化 → Markdown出现LLM任务总结。

模型只接收合成材料，没有发送个人真实对话。工具输出的合成哨兵未出现在输入快照。真实调用可能消耗既有账户额度，不代表免费或覆盖了所有provider。
