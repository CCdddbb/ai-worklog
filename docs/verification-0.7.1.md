# 0.7.1 验证记录：周趋势点选与采集缺口

本轮只使用临时数据库、合成会话和仓库内的测试数据，不调用真实模型。

## 修复内容

- 周趋势不再“跳走”：点折线数据点或图下数值按钮只在周页选中当天，下方「当天的工作进展」随之更新；进入当天工作台仍需显式点「查看当天记录」。此前两个入口都调用 `openDay`，所以一点就回到今日工作台。
- 采集缺口按日期窗口归因：
  - 最后写入时间早于当天窗口起点的文件不读取、也不计入当天的 `omitted_files`；它们不可能包含当天事件，此前却按“全库未读文件”记成缺口。
  - 窗口内超过 64MiB 的文件不再整文件丢弃，改为读取到上限并以 `truncated_files` 披露截断；若文件尾部最后一条记录早于窗口，则直接判为不相关，不读 64MiB。
  - 窗口外超长行继续单独披露（`out_of_window_oversized_lines`），不计入缺口。
  - 缺口键集中在 `worklog.adapters.GAP_KEYS`，周记录与报告文档共用同一份定义。
- 启动后由轮询线程重扫本周已过去的日期，用同一口径覆盖旧版本留下的覆盖记录；今天由启动导入负责，未来日期不扫描。
