# 0.6 验证记录：删除无效记录、忽略与恢复

本轮只使用临时数据库和虚构会话，不扫描个人日志，不调用真实模型。

- `python -m pytest`：**184 项通过**（含 11 个子测试），新增用例覆盖：
  - 删除任务同时清除 `tasks`、`summaries`、`task_reviews`、`task_git`、`automatic_coverage`、`task_automation`、`conversation_sources` 及该任务产生的 `work_records`、历史、会话关联和对话分项。

  - 忽略后自动记录不再为该会话建任务，也不计入待整理；恢复后重新生成。
  - `/api/task-delete`、`/api/session-ignore` 的本地令牌、同源校验和未知字段拒绝。

## 未验证

- 真实浏览器中的删除确认弹窗、批量删除与「恢复」点击流程没有自动化用例，仅手动检查；自动化覆盖停在 Python 接口与数据库层。
- 大规模数据库下的批量删除耗时、并发写入冲突、撤销与回收站（本轮不提供）。
- 忽略会话在真实自动记录长跑中的表现，以及跨设备/多数据库文件的迁移行为。
- 真实模型草稿在删除前的导出或留存流程。
