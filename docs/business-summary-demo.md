### 修复 OAuth 登录回调丢失 state 参数

- 状态：助手报告已解决，待人工核验
- 问题/目标：OAuth 登录回调未保留 state 参数，导致用户无法完成登录；最初只把 state 拼到登录 URL，实际回归仍失败，回调页依然取不到 state。
- 处理措施：
  - 先尝试把 state 拼到登录 URL，但该方案未通过实际回归，回调页仍取不到 state。
  - 改为在跳转前保存 state，回调页读取并校验后再清理，替换只拼接 URL 的方案。
- 结果/解决的问题：助手报告该修改修复了状态参数丢失导致的登录失败，并放弃只拼接 URL 的方案。
